# Arabic Summarizer

ماژول آفلاین خلاصه‌سازی متون عربی - پروژه کارآموزی تیم BitForge

## نصب

```bash
pip install -r requirements.txt
```

## اجرای API

```bash
uvicorn api.main:app --reload
```

## اجرای دموی گرافیکی

```bash
python ui/app_gradio.py
```

## ساختار پروژه

به فایل `docs/architecture.md` مراجعه کنید.
